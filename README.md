# Sailing Reorderer

Reorder facilities in the sailing side panel.

In addition to the in-game reorder feature found at the shipyard, this plugin has the following features:

- Reorder facilities outside the shipyard
- Reorder fixed facilities (e.g. steering)
- Align the steering assign button
- Expand the UI to fit more facilities without scrolling
- Per boat configuration
